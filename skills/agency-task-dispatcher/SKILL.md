## TRIGGER

Активировать скилл когда:
- Пользователь загружает транскрипт планерки / звонка
- Пользователь присылает голосовой дамп с задачами
- Пользователь пишет: «разбери задачи», «распредели», «сделай таблицу задач»

---

## RULES

**1. Парсинг задач**
Прочитать весь ввод. Извлечь каждое actionable item:
- Игнорировать рассуждения, контекст, истории — только конкретные действия
- Если действие неявное — переформулировать в глагол + объект: «Сделать → записать → опубликовать»
- Одна мысль = одна задача. Если мысль содержит два действия — дробить

**2. Назначение исполнителей**
Назначить задачу по зоне ответственности из TEAM CONTEXT выше:
- Визуал / монтаж / B-roll → **Дана**
- Публикации / сторис / Direct / лиды → **Амина**
- Воронки / автоматизация / платежи / лендинги → **Диас**
- Тренды / хуки / анализ конкурентов → **Ансаган**
- Сорсинг / наличие товара / фабрики → **Сай**
- Клиенты Шанхай / логистика → **Мухаммад**
- Ассистирование на выезде / каталогизация / короткий ресерч → **Мансур** (только до 3 ч/день)
- Стратегия / финальный аппрув / съемки лицо / закрытие сделок → **Данияр**
- Нет подходящего исполнителя → флаг **[⚑ CEO]** — Данияр принимает решение

**3. Дедлайн**
- Если дедлайн назван явно — вставить как есть
- Если не назван — поставить `[уточнить]`
- Срочные задачи (слова «сегодня», «срочно», «до конца дня») → дедлайн = `сегодня, 19:00`

**4. Формат вывода — строго Notion-ready**

Таблица + блок нераспределённых задач (если есть).

Никаких приветствий. Никаких вводных фраз. Сразу таблица.

```
## ЗАДАЧИ — [дата / название встречи если указано]

| # | Задача | Исполнитель | Дедлайн | Контекст / Примечание |
|---|--------|-------------|---------|----------------------|
| 1 | [глагол + объект] | [имя] | [дата или уточнить] | [1 строка контекста] |
| 2 | ... | | | |

---

⚑ НЕРАСПРЕДЕЛЁННЫЕ (решение за CEO):
- [задача] — причина: [почему не ясен исполнитель]
```

---

## HARD RULES

- Выдавать только таблицу и блок нераспределённых. Никакого комментария после.
- Не придумывать дедлайны — только явные или `[уточнить]`.
- Не объединять задачи разных исполнителей в одну строку.
- Мансуру — не назначать задачи дольше ~2 часов. Если задача крупная → флаг `[⚑ CEO]` для перераспределения.
- Если транскрипт пустой или без actionable items → вывести: `Задач не обнаружено. Уточни ввод.`
- Перед запуском скилла в новой сессии: прочитать `TEAM_ROLES_KPI.md` на наличие изменений в составе команды.
